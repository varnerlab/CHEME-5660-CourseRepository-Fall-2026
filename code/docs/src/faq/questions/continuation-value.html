How do we compute the continuation value at a lattice node?

  1. Short answer
  2. Worked explanation
  3. Notes and sources

1 Short answer

Weight the option values at the two next nodes by the risk-neutral probabilities, add them, and discount one step. The American node value is the larger of this continuation value and the payoff from exercising now.

2 Worked explanation

What are the two values at a node? At node (t,k)(t,k) of the lattice, with share price St,kS_{t,k}, the American holder compares exercising now, which pays V(K,St,k)V(K,S_{t,k}), with holding for one more step. The value of holding is the continuation value:

Ht,k=𝒟t+1,t−1(gy)⋅(qV̂t+1,k+1+(1−q)V̂t+1,k). H_{t,k}=\mathcal{D}^{-1}_{t+1,t}(g_{y})\cdot\bigl(q\,\hat{V}_{t+1,k+1}+(1-q)\,\hat{V}_{t+1,k}\bigr).

The node value is the larger of the two:

V̂t,k=max{V(K,St,k),Ht,k}. \hat{V}_{t,k}=\max\bigl\{V(K,S_{t,k}),~H_{t,k}\bigr\}.

We weight the values at the up and down nodes by qq and 1−q1-q, add them, and discount one step with 𝒟t+1,t−1(gy)=e−gyΔt\mathcal{D}^{-1}_{t+1,t}(g_{y})=e^{-g_{y}\Delta t}. The values at the next nodes must already be known, so we start at expiration, where each node value is the payoff, and work backward to the root.

Hull’s two-step put, node by node. The L9b example has S0=50S_{0}=50 USD/share, K=52K=52 USD/share, u=1.2u=1.2, d=0.8d=0.8, Δt=1\Delta t=1 year, and gy=0.05yr−1g_{y}=0.05\,\mathrm{yr}^{-1}, so q=0.6282q=0.6282, 1−q=0.37181-q=0.3718, and e−0.05=0.9512e^{-0.05}=0.9512. At expiration the share prices are 72, 48, and 32 USD/share, and the put pays 0, 4, and 20 USD/share. Working backward:

Node Exercise Continuation value Value
Up, S1,1=60S_{1,1}=60 0 0.9512(0.6282⋅0+0.3718⋅4)=1.410.9512\,(0.6282\cdot0+0.3718\cdot4)=1.41 1.41
Down, S1,0=40S_{1,0}=40 12 0.9512(0.6282⋅4+0.3718⋅20)=9.460.9512\,(0.6282\cdot4+0.3718\cdot20)=9.46 12
Root, S0=50S_{0}=50 2 0.9512(0.6282⋅1.41+0.3718⋅12)=5.090.9512\,(0.6282\cdot1.41+0.3718\cdot12)=5.09 5.09

The holder holds at the up node and at the root, and exercises at the down node.

At the root, the down branch uses the node value 12, not the continuation value 9.46: each earlier node uses the values after the decision at the later nodes. That is how one early exercise at t=1t=1 raises the root value. The European put must hold at the down node, so its root value is 0.9512(0.6282⋅1.41+0.3718⋅9.46)=4.190.9512\,(0.6282\cdot1.41+0.3718\cdot9.46)=4.19 USD/share.

How do extrinsic value and the early-exercise premium differ? Both are differences, but they compare different things. Extrinsic value compares the American contract’s value at a node with exercising now at that node, EV=V̂t,k−V(K,St,k)E_{V}=\hat{V}_{t,k}-V(K,S_{t,k}). At the root, EV=5.09−2=3.09E_{V}=5.09-2=3.09 USD/share. At the down node, EV=12−12=0E_{V}=12-12=0, because the holder exercises there. The early-exercise premium compares two contracts at the root, 𝒫AM−𝒫EU=5.09−4.19=0.90\mathcal{P}^{\text{AM}}-\mathcal{P}^{\text{EU}}=5.09-4.19=0.90 USD/share. A contract can have a large extrinsic value and no early-exercise premium: an at-the-money call on a share with no dividends is an example (L10a).

Try it. What is the extrinsic value at the up node at t=1t=1?

Show the answer
Exercising pays nothing there, because the share price of 60 USD/share is above the strike, and the node value is 1.41 USD/share. The whole value, EV=1.41−0=1.41E_{V}=1.41-0=1.41 USD/share, is extrinsic.
