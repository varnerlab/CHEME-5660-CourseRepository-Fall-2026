How does the Longstaff–Schwartz regression decide when to exercise early?

  1. Short answer
  2. Worked explanation
  3. Notes and sources

1 Short answer

At each exercise date, we fit a curve to the in-the-money paths that estimates the value of holding from today’s share price alone. A path exercises when exercising now pays more than that estimate. The curve is used only to make this choice; each path then keeps the cash flow it actually receives.

2 Worked explanation

What does the regression estimate? At date tt, the holder of an American put knows today’s share price Si(t)S_{i}(t), but not where the path goes next. The value of holding is the expected discounted cash flow from holding, given today’s share price. A single path’s cash flow Yi(t)Y_{i}(t) depends on that path’s own future, which the holder cannot see. Regressing Yi(t)Y_{i}(t) on Si(t)S_{i}(t) fits one curve through the cash flows of all the in-the-money paths, so each path’s own future is just one point in the fit. The fitted curve Ĥt(S)=β0+β1S+β2S2\hat{H}_{t}(S)=\beta_{0}+\beta_{1}S+\beta_{2}S^{2} estimates the value of holding at each share price.

One backward step on the eight paths. In the L10a example, K=1.10K=1.10 USD/share, gy=0.06yr−1g_{y}=0.06\,\mathrm{yr}^{-1}, and the exercise dates are one year apart. At t=2t=2, five paths are in the money. Discounting their later cash flows one step and fitting gives the paper’s reported fit, Ĥ2(S)=−1.070+2.983S−1.813S2\hat{H}_{2}(S)=-1.070+2.983S-1.813S^{2}. Look at path 4. With hindsight, holding was better: its realized cash flow from holding, 0.170, beats exercising for 0.13. At t=2t=2, though, the rule compares the payoff now with the fitted curve at S4(2)=0.97S_{4}(2)=0.97, which puts the value of holding at 0.118. So the rule exercises. The decision depends on path 4 only through its share price today.

Why fit only the in-the-money paths? An out-of-the-money path pays nothing if exercised, so holding is always at least as good, and there is no decision to make. The curve is only needed where exercising pays something, so Longstaff and Schwartz fit it there, and all three coefficients go to the share prices where the choice matters.

Why keep the realized cash flows instead of the fitted values? After the decision, a path that holds keeps its realized Yi(t)Y_{i}(t); only a path that exercises changes its cash flow, to V(K,Si(t))V(K,S_{i}(t)). Suppose instead that each in-the-money path took the larger of VV and Ĥt\hat{H}_{t}. Wherever the curve came out too high, we would keep its value; wherever it came out too low, the payoff would replace it. The curve’s errors would no longer cancel, and the premium would drift up: on the eight paths, to 0.1178 USD/share instead of 0.1144. Keeping the realized cash flows uses the curve only to choose when to exercise. If we fit the curve on one set of paths and price on new paths, every cash flow is one a holder could actually receive, so a poor curve can only lower the price. On the same eight paths, the curve has partly seen each path’s future, so 0.1144 can still be a little high; with thousands of paths, as in Task 2 of the example, this effect is small.

Discounting the date-1 cash flows to today and averaging gives the American premium, 0.1144 USD/share. Always holding on the same paths gives the European premium, 0.0564 USD/share, so the early-exercise premium is about 0.058 USD/share.
