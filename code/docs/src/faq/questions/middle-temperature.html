Why does a middle temperature give lower volatility than greedy or random choice?

  1. Short answer
  2. Worked explanation
  3. Notes and sources

1 Short answer

When agents are greedy, those with similar policies tend to switch at the same time, so many end up on the same side. When agents choose at random, they ignore the scores and do about as well as coin flips. In the example, a middle temperature gave lower volatility than both. A likely reason: agents still favor their better policies, but they do not all switch at once.

2 Worked explanation

What did the example measure? The crowded game in the thermal minority game example has N=641N=641 agents, each with J=2J=2 policies. The memory is m=6m=6, so there are P=64P=64 histories and α=P/N≈0.1\alpha=P/N\approx 0.1. The L12a slides report the volatility per agent, σA2/N\sigma_{A}^{2}/N, averaged over three games.

Why are greedy agents so volatile? There are many more agents than histories, so many agents hold policies that act alike. Those policies get the same score updates, so the agents holding them tend to switch at the same time. A large group lands on the same side, the attendance swings far from zero, and that side loses. Then the scores shift back, and much of the group switches back together. The attendance keeps swinging from one side to the other.

Why doesn’t random choice fix this? At T=∞T=\infty, each agent picks one of its two policies at random every round. No group moves together, so the crowding goes away, and the volatility per agent falls to about 1, the coin-flip value. But random choice also ignores the scores, which track which policies tend to land in the minority.

Why is a middle temperature better than both? The example shows that it is, but not why. A likely reason: at T=100T=100, each agent still favors its higher-scoring policy, so the scores still guide its choice. But when the scores change, only some of the agents with similar policies switch in a given round. The switches are spread over many rounds, so the swings are smaller. In the example, the volatility per agent fell to 0.46, below the coin-flip value.

A traffic analogy: drivers choose between two roads every morning, and the less crowded road is faster. If every driver takes the road with the better record, drivers with the same record all pick the same road, and it jams. If every driver flips a coin, the roads split about evenly, give or take chance. If each driver usually takes the road with the better record but sometimes takes the other, the records still guide the drivers, but they do not all switch at once.

What is the best temperature? We ran the sweep only at α≈0.1\alpha\approx 0.1 with J=2J=2. The volatility stays near the greedy value up to about T=0.3T=0.3, drops between T=1T=1 and T=10T=10, is lowest near T=100T=100, and climbs back toward the random-choice value above about T=1,000T=1{,}000. The course gives no formula for the best temperature. To find it for another α\alpha or JJ, change the constants and rerun Task 3 of the example. For what TT means, see what the temperature does.
