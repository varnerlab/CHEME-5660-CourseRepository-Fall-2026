When do independent single-asset models agree with MA-GBM?

  1. Short answer
  2. Worked explanation
  3. Notes and sources

1 Short answer

When the individual parameters match, the two constructions have the same joint distribution if all cross-asset covariances are zero. Zero covariance implies independence here because the model’s shocks are jointly normal.

2 Worked explanation

Suppose both constructions use the same initial prices, drifts, and individual volatilities. The independent single-asset simulations then have the same joint distribution as the multiple-asset model when all cross-asset covariances are zero. Even when the cross covariances are nonzero, each asset keeps the same individual distribution in either construction; what changes is how the assets move together.

The agreement is exact because the model uses jointly normal growth-rate shocks. For a jointly normal vector, a diagonal covariance matrix gives independent components. When the correlations are very weak, independent simulation can be a reasonable approximation in a small example. Whether the difference matters depends on the portfolio, horizon, and number of assets; many small cross terms can add up.

Zero correlation does not establish independence for arbitrary data. Suppose X∈{−1,0,1}X\in\{-1,0,1\} takes each value with equal probability, and define Y=X2Y=X^2. Their covariance is zero, yet knowing XX determines YY exactly. In GBM, the joint-normality assumption supplies the extra structure that turns zero covariance into independence.

We should also distinguish equality in distribution from identical simulated paths. Two independent runs can follow different paths even when they use exactly the same model.
