How do we read a Wolfram market rule number?

  1. Short answer
  2. Worked explanation
  3. Notes and sources

1 Short answer

A rule number is a short name for a table with nine entries: the next intention for each possible sum of the four neighbors’ intentions. Written in base 3, each digit of the rule number is one entry. The trader does no other math. It adds up its neighbors’ codes and looks up the entry for that sum.

2 Worked explanation

What does a trader look up? Each interior trader codes its four neighbors’ intentions as Buy =0=0, Hold =1=1, and Sell =2=2, and adds them up. The neighbor sum ci(t)c_{i}(t) runs from 0 (four Buy neighbors) to 8 (four Sell neighbors). The trader’s rule is a table with one entry aca_{c} for each sum, which gives its next intention:

zi(t)=aci(t)(Ri) z_{i}(t)=a^{(R_{i})}_{c_{i}(t)}

How do nine entries become one number? Write them as the digits of a base-3 number, with a8a_{8} on the left and a0a_{0} on the right:

R=(a8a7⋯a1a0)3=∑c=08ac3c R=\left(a_{8}a_{7}\cdots a_{1}a_{0}\right)_{3}=\sum_{c=0}^{8}a_{c}\,3^{c}

For example, Rule 19280 is (222110002)3(222110002)_{3}:

Neighbor sum cc 8 7 6 5 4 3 2 1 0
Entry aca_{c} 2 2 2 1 1 0 0 0 2
Next intention Sell Sell Sell Hold Hold Buy Buy Buy Sell

To check:

R=2⋅38+2⋅37+2⋅36+35+34+2=13,122+4,374+1,458+243+81+2=19,280 \begin{aligned} R&=2\cdot 3^{8}+2\cdot 3^{7}+2\cdot 3^{6}+3^{5}+3^{4}+2\\ &=13{,}122+4{,}374+1{,}458+243+81+2=19{,}280 \end{aligned}

How do we get the digits back from the number? Divide by 3 and keep the remainder, then repeat with the quotient. The remainders are a0,a1,…a_{0},a_{1},\dots in order. For Rule 19280, 19,280=3⋅6,426+219{,}280=3\cdot 6{,}426+2, so a0=2a_{0}=2. Next, 6,426=3⋅2,142+06{,}426=3\cdot 2{,}142+0, so a1=0a_{1}=0, and so on. The nine remainders are 2,0,0,0,1,1,2,2,22,0,0,0,1,1,2,2,2 for a0a_{0} through a8a_{8}. The rule_table(...) function in the rules example does this for us.

Why does Rule 19280 buy at sum 1 while Rule 19286 sells? Because their tables say so; there is nothing to calculate. Rule 19286 is (222110022)3(222110022)_{3}. It differs from Rule 19280 only in the 313^{1} place, where 0 (Buy) becomes 2 (Sell). Raising that digit by 2 adds 2⋅31=62\cdot 3^{1}=6, so 19,280+6=19,28619{,}280+6=19{,}286. We choose the table, and the rule number is just its name.

Why only the sum? A trader sees only the sum of its neighbors’ codes. It does not see which neighbor intends what, or even how many intend each action. For example, two Sell and two Buy neighbors give a sum of 4, the same as four Hold neighbors. Using the sum keeps the table to nine entries, so there are 39=19,6833^{9}=19{,}683 possible rules.

How were these rules chosen? They were chosen, not fit to data. Under Rule 19280, the market settles into a mix of all three intentions. The lecture compares pairs of rules that differ in one entry, as a model of a small change in how traders behave. The rules example lists all 18 rules that differ from Rule 19280 in one entry. Each trader could have its own rule RiR_{i}, but the lecture uses only two rules. For what a switch does, see how many traders must switch.

Try it. Rule 19280 gives Hold at sum 4. What is the rule number if that entry becomes Sell? What if it becomes Buy?

The digit in the 34=813^{4}=81 place changes from 1 to 2, or from 1 to 0. The rule number becomes 19,280+81=19,36119{,}280+81=19{,}361 or 19,280−81=19,19919{,}280-81=19{,}199. Both appear in the example’s list.
