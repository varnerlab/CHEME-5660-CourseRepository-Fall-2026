VLQuantitativeFinancePackage.MPCPortfolio.MyAllocationProblem — Type
MyAllocationProblem

One allocation decision: γ (preference weights, dimensionless), μ_g (expected growth, yr⁻¹), Σ_g (growth covariance, yr⁻²), prices (USD/share), W (equity, USD), g_f (risk-free growth, yr⁻¹), the shared constraints::MyConstraintSet and hedge (one flag per name: a hedge-pool name). In the γ-based rules a hedge name with γᵢ ≤ 0 is a free variable above its floor with no utility term, so it is bought only when the β or volatility cap makes it worth its budget; in the 130/30 it is long-only.

VLQuantitativeFinancePackage.MPCPortfolio.MyCESRule — Type
MyCESRule

CES utility (Σ{γᵢ>0} γᵢ nᵢ^ρ)^(1/ρ) with ρ = 1 − 1/η (CHEME-5660 `allocateces: nᵢ ∝ (γᵢ/Sᵢ)^η under a budget alone). Fieldη` (elasticity of substitution, dimensionless, > 0): η > 1 (0 < ρ < 1) maximizes Σ γᵢ nᵢ^ρ; 0 < η < 1 (ρ < 0) minimizes Σ γᵢ nᵢ^ρ; η = 1 is Cobb-Douglas. Names with γᵢ ≤ 0 sit at the floor ε, except hedge names, which are free above it.

VLQuantitativeFinancePackage.MPCPortfolio.MyCESWeightRule — Type
MyCESWeightRule

Weight-based CES (CESw): U = (Σ_{γᵢ>0} γᵢ·wᵢ^ρ)^(1/ρ) with ρ = 1 − 1/η and dollar weights wᵢ = nᵢ·Sᵢ/W (dimensionless). Under a budget alone wᵢ ∝ γᵢ^η, so a split (Sᵢ down, nᵢ up, γᵢ unchanged) leaves the book unchanged; every other rule (shared limits, ε pins, hedge names, η = 1 as Cobb-Douglas) is that of MyCESRule. Field η (elasticity of substitution, dimensionless, > 0).

VLQuantitativeFinancePackage.MPCPortfolio.MyConstraintSet — Type
MyConstraintSet

The constraint set shared by every portfolio rule:

  • w_max: per-name weight cap (dimensionless; applies to |wᵢ| for signed rules); the scalar default of w_cap
  • w_cap: per-name weight cap on |wᵢ| (dimensionless, one per name; default fill(w_max, K))
  • s_max: per-sector weight cap (dimensionless; s_max ≥ 1 means no sector cap)
  • σ_g_max: cap on the portfolio growth-rate SD √(wᵀΣ_g w) (yr⁻¹)
  • K_turnover: spread-cost budget (USD), c̄·Σ|nᵢ − nprevᵢ| ≤ Kturnover
  • c̄: turnover cost per share (USD/share)
  • sector: GICS sector per name
  • n_prev: holdings before the solve (shares)
  • ε: floor for names with γ ≤ 0 under the log/CES utilities (shares, default 1e-3)
  • β: each name's signed β on the market (dimensionless, default 0)
  • β_max: cap on the portfolio β Σ βᵢwᵢ (dimensionless; cash has β = 0; default Inf = no cap)

MyStoneGearyRule

Stone–Geary utility: maximize Σ{γᵢ>0} γᵢ·log(nᵢ − bᵢ) with nᵢ ≥ bᵢ for every name, where the baseline bᵢ = `baselinefrac·W/Sᵢ shares (baseline_frac` dimensionless, e.g. 0.01 = a 1% core position). Names with γᵢ ≤ 0 are held at bᵢ, except hedge names, which are free above it.

VLQuantitativeFinancePackage.MPCPortfolio._ces_objective — Method
_ces_objective(η::Float64, a::Vector{Float64})::Function

The objective!(m, x, γp) closure of _solve_utility for CES with elasticity η ≠ 1 over the preferred holdings x, on the scaled variable zₖ = aₖ·xₖ (aₖ in 1/units of x). With ρ = 1 − 1/η it adds

  • η > 1: [z, 1, t] in PowerCone(ρ) (t ≤ z^ρ) and returns Σ γₖ tₖ;
  • η < 1: [t, z, 1] in PowerCone(η) (t ≥ z^ρ) and returns −Σ γₖ tₖ.

The argmax is that of (Σ γₖ xₖ^ρ)^(1/ρ) for any a > 0.

VLQuantitativeFinancePackage.MPCPortfolio.add_shared_constraints! — Method
add_shared_constraints!(m::JuMP.Model, n, p::MyAllocationProblem; signed=false, κ=1.0)

Add the shared constraint set to m for the share vector n (length K, shares; entries are JuMP variables/affine expressions, or constants for pinned names) and return the weight expressions w = n·S/W (dimensionless, Vector{AffExpr}). Constraints, following engine Allocator.jl:115-163:

  • Budget: Σ nᵢSᵢ ≤ W·κ (USD). With signed=true this is net exposure ≤ 1 (cash ≥ 0).
  • Per-name cap: wᵢ ≤ wcapᵢ·κ for every name, pinned ones included (a pinned name's constant row is checked directly and only sent to the solver when violated); with signed=true also wᵢ ≥ −wcapᵢ·κ, i.e. |wᵢ| ≤ w_capᵢ·κ.
  • Sector cap (only when s_max < 1): Σ{i∈s} wᵢ ≤ smax·κ per sector; with signed=true the net sector weight is capped on both sides, |Σ{i∈s} wᵢ| ≤ smax·κ.
  • β cap (only when βmax is finite): Σ βᵢwᵢ ≤ βmax·κ (dimensionless) on the signed βᵢ, cash at β = 0; with signed=true on the signed weights. A constant row (pinned names only) is checked directly, like the per-name cap.
  • Volatility cap: ‖Lᵀw‖ ≤ σgmax·κ (yr⁻¹) as a second-order cone, LLᵀ = Σg + 1e-8·I (yr⁻²); skipped when σg_max is infinite.
  • Spread-cost budget (the trial's turnover rule): c̄·Σ{free i} |nᵢ − κ·nprevᵢ| ≤ Kturnover·κ (USD), on the non-pinned names only (engine semantics: pinned names' churn is not counted). The slack variables are skipped when c̄ = 0 or when no feasible point can violate the budget: c̄·max‖n − nprev‖₁ ≤ Kturnover, with max‖·‖₁ ≤ Beff/min Sᵢ + Σ nprevᵢ (long-only; Beff = W − pinned cost, USD) or Σ (wcapᵢ·W/Sᵢ + |nprevᵢ|) (signed), both over the free names.

The sign of n is the caller's: long-only rules declare nᵢ ≥ 0 (or a floor) as variable bounds, and the long-only turnover guard relies on it; signed rules pass n = n⁺ − n⁻. κ (dimensionless, a number or a JuMP variable) homogenizes every right-hand side for fractional programs (y = κ·n, e.g. the tangent rule); with a variable κ, pass no constant pins.

VLQuantitativeFinancePackage.MPCPortfolio.allocate — Function
allocate(rule::AbstractPortfolioRule, p::MyAllocationProblem)::MyAllocationResult

Solve one allocation under the shared constraints (add_shared_constraints!). Shares n are continuous (shares), weights w = n·S/W. Status :no_preferred when no γᵢ > 0 (utility rules return their pins without a solve, except Stone–Geary under a finite β cap); :infeasible or :solver_failed return n = constraints.n_prev. In the utility rules a hedge name (p.hedge) with γᵢ ≤ 0 is a free variable above its pin, with no utility term and a cost of 1e-6 per unit of weight (the tie-break); a second solve with the other names' shares fixed then minimizes the hedge weight, so a hedge sits above its pin only as far as a binding β or volatility cap needs it. Every other γᵢ ≤ 0 name is pinned.

VLQuantitativeFinancePackage.MPCPortfolio.allocate — Method
allocate(rule::MyCESRule, p::MyAllocationProblem)::MyAllocationResult

CES with ρ = 1 − 1/η, nᵢ in shares, γ ≤ 0 names pinned at ε shares (free hedge names: nᵢ ≥ ε, no utility term). Under a budget alone nᵢ ∝ (γᵢ/Sᵢ)^η for every η (CHEME-5660 allocate_ces). Both cones work on the scaled share count zᵢ = aᵢ·nᵢ (_ces_objective), with aᵢ = Σ_{γ>0} Sⱼ / W (1/shares), so zᵢ = 1 at the book with equal share counts over the preferred names.

  • η > 1 (0 < ρ < 1): maximize Σ_{γ>0} γᵢ·tᵢ with (zᵢ, 1, tᵢ) ∈ PowerCone(ρ), i.e. tᵢ ≤ zᵢ^ρ.
  • 0 < η < 1 (ρ < 0): minimize Σ_{γ>0} γᵢ·tᵢ with (tᵢ, zᵢ, 1) ∈ PowerCone(η), i.e. tᵢ ≥ zᵢ^ρ. This maximizes (Σ γᵢ zᵢ^ρ)^(1/ρ), since 1/ρ < 0.
  • (plan decision) The scale c = W/Σ_{γ>0} Sᵢ (shares) replaces W/mean(S), and the η > 1 branch is scaled too. A common factor c scales every term by c^(−ρ), which leaves the argmax unchanged and keeps zᵢ = O(1) at any W and K (with W/mean(S), zᵢ ≈ 1/K at the optimum and the cone held (1/K)^(−19) at η = 0.05).
  • η = 1: allocate(MyCobbDouglasRule(), p).

VLQuantitativeFinancePackage.MPCPortfolio.allocate — Method
allocate(rule::MyStoneGearyRule, p::MyAllocationProblem)::MyAllocationResult

Stone–Geary: maximize Σ{γ>0} γᵢ·log(nᵢ − bᵢ) via exponential cones on the excess shares, with bᵢ = baselinefrac·W/Sᵢ shares (fractional), nᵢ ≥ bᵢ, and γ ≤ 0 names held at bᵢ (free hedge names: nᵢ ≥ bᵢ, no utility term). Returns :infeasible with nprev when Σ bᵢSᵢ > W (USD), or when the baselines break another limit (e.g. Σ βᵢbᵢSᵢ/W > βmax). With no γ > 0 (:no_preferred) it returns n = b, except under a finite βmax: with free hedge names it returns the least hedge holding above b that meets every shared limit, and without them it checks Σ βᵢbᵢSᵢ/W ≤ βmax; when neither works it returns nprev with :infeasible (`:solverfailed` if the hedge solve fails).

VLQuantitativeFinancePackage.MPCPortfolio.budget_only_weights — Function
budget_only_weights(rule, γ::AbstractVector, S::AbstractVector; W::Real, ε::Real=1e-3)::Vector{Float64}

Dollar weights (dimensionless, Σ = 1) under the budget alone, in closed form. Names with γᵢ ≤ 0 hold ε shares (weight ε·Sᵢ/W); the budget B = W − Σ{γ≤0} ε·Sᵢ (USD) left over is split among the names with γᵢ > 0: Cobb-Douglas in proportion to γᵢ, weight-based CES in proportion to γᵢ^η, CES in proportion to Sᵢ·(γᵢ/Sᵢ)^η (nᵢ ∝ (γᵢ/Sᵢ)^η, η = 1 is Cobb-Douglas). With no γ > 0 it returns the pin weights only, as allocate does (`:nopreferred). The closed form assumes no free hedge names: every γ ≤ 0 name is pinned at ε. On a problem with hedge names it is not the optimum ofallocate.γhas no units,Sis USD/share andW` is USD.

VLQuantitativeFinancePackage.MPCPortfolio.allocate — Method
allocate(::MyMinVarRule, p::MyAllocationProblem)::MyAllocationResult

Minimum variance in two-fund form (R24), over long-only shares n ≥ 0 (shares, no ε pins):

  1. Mix: minimize wᵀΣg w (yr⁻²) at Σwᵢ = sdir = max_investable(p) (to within 1e-7) under the budget, per-name, sector, β and turnover limits, without the volatility cap.
  2. Scale: w = c·wmix with c = min(1, σgmax/√(wmixᵀΣg wmix)); the rest is cash.

VLQuantitativeFinancePackage.MPCPortfolio.allocate — Method
allocate(::MyTangentRule, p::MyAllocationProblem)::MyAllocationResult

Tangent portfolio in two-fund form (R24), with excess growth e = μg − gf (yr⁻¹), over long-only shares (no ε pins). Every solve uses the budget, per-name, sector, β and turnover limits and Σwᵢ = sdir = `maxinvestable(p)` (to within 1e-7), without the volatility cap; the cap enters only in the final scale.

  1. Best excess growth δ = max eᵀw (yr⁻¹) over that set (a cone LP). When δ is not positive (δ ≤ 1e-6·sdir·max|eᵢ|, the solver tolerance), no feasible portfolio has positive excess growth and the rule returns the (R24) min-variance portfolio with status `:fallbackminvar`.
  2. Mix by Charnes–Cooper homogenization. With y = κ·n (shares) and κ ≥ 0, and v = κ·w the weights add_shared_constraints!(m, y, q; κ=κ) returns: minimize vᵀΣg v subject to eᵀv = δ, Σv ≥ (sdir − 1e-7)·κ, y ≥ 0, and the budget, per-name, sector and turnover rows with their right-hand sides scaled by κ. Then wmix = v/κ. Fixing eᵀv to δ instead of 1 leaves the optimum unchanged (the Sharpe ratio is scale-free) and keeps κ = δ/eᵀw ≥ 1, so dividing by κ never amplifies solver error. A failed (or infeasible) solve here, after δ > 0 was found, returns n = nprev with :solver_failed.
  3. Scale: w = c·wmix with c = min(1, σgmax/√(wmixᵀΣg wmix)); the rest is cash.

s_star = Σwᵢ of the returned portfolio. Returns n = nprev with :infeasible / `:solverfailedwhen the limits cannot be met, and with:infeasible` when the scaled portfolio breaks the turnover budget.

VLQuantitativeFinancePackage.MPCPortfolio.allocate — Method
allocate(rule::MyLongShortCDRule, p::MyAllocationProblem)::MyAllocationResult

130/30 long-short CD via exponential cones on n⁺ ≥ 1e-8 and n⁻ ≥ 1e-8 (shares). Long set: γ > 0 names and hedge names (p.hedge); short set: γ < 0 names that are not hedge names; other γ = 0 names are fixed at 0. A hedge name with γ ≤ 0 is a long variable (n⁺ ≥ 1e-8) with no utility term and the utility rules' tie-break cost of 1e-6 per unit of weight; as in the utility rules, a second solve with every other name's shares fixed then minimizes the hedge weight, so a hedge is bought only as far as a binding limit (β or volatility cap) needs it.

Constraints: Σ{long} wᵢ ≤ longcap, Σ{short} |wᵢ| ≤ shortcap, Σwᵢ ≤ netcap, plus `addsharedconstraints!(…; signed=true)`: net exposure ≤ 1 (cash ≥ 0), |wᵢ| ≤ wcapᵢ, |net sector weight| ≤ smax, Σβᵢwᵢ ≤ βmax and √(wᵀΣg w) ≤ σgmax (yr⁻¹) on the signed weights, and the turnover budget on the signed share changes (USD). `sstar` is the net exposure Σwᵢ.

Special cases: no γ > 0 → :no_preferred with n = 0 (all cash, no solve); an empty short set → allocate(MyCobbDouglasRule(), p) with status :long_only_fallback (a failed CD solve keeps its status). :infeasible / :solver_failed return n = n_prev.

limits_day(ctx::MyStudyContext, runs::Vector{MyStudyRun}, s::Int)::DataFrame

The budget-only allocation of every run on run row s (market-data row ctx.rows[s]), one DataFrame row per run and ticker with columns label, allocator, eta, date, ticker, gamma, price, weight, closed_form, status, solver. Throws ArgumentError for an allocator other than CD, CES and CESw, a screen other than :fixed, or settings whose context_key differs from the context's.
