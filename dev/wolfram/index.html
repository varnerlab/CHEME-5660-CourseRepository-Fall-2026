Wolfram markets

VLQuantitativeFinancePackage.WolframMarkets is the simulator of the Wolfram-rule market paper, J. D. Varner, Wolfram-markets-abm-paper (executed snapshot, commit 33ebbaa). Traders sit on a grid and choose Buy, Hold or Sell by a two-dimensional totalistic Wolfram rule that depends on the sum of their four neighbors. A ring of edge traders reads the price against a moving-average band and feeds that signal into the grid, and the orders clear against a finite constant-product dealer whose cash-to-inventory ratio is the price. The port reproduces the paper's final-grid SHA-256 fingerprints and per-run metrics.

The submodule has its own namespace. Use it qualified:

import VLQuantitativeFinancePackage
import VLQuantitativeFinancePackage.WolframMarkets as WM

config = WM.build(WM.MyModelBConfiguration, (number_of_rows = 32, number_of_cols = 32, steps = 4000,
    seed = 1, λ = 0.02, minority_fraction = 0.25, cost_basis_rule = false, market_maker_capacity = 100.0))
result = WM.simulate_checked(config; minority_population = :interior, boundary_mode = :hold,
    rule_activation_step = 1001, verbose = false)

VLQuantitativeFinancePackage.WolframMarkets — Module

VLQuantitativeFinancePackage.WolframMarkets: the reserve-clearing cellular-automaton market of the Wolfram-rule market paper (J. D. Varner, github.com/varnerlab/Wolfram-markets-abm-paper, executed snapshot at commit 33ebbaa).

Traders sit on a grid and update by a two-dimensional totalistic Wolfram rule over three states (Buy, Hold, Sell). A ring of edge traders reads an exponential-moving-average band on the price and feeds that signal into the grid, and the orders clear against a finite constant-product dealer whose cash-to-inventory ratio is the price. The code is the paper's simulator, copied from the snapshot's src/ with the edits listed below.

Use it qualified: import VLQuantitativeFinancePackage.WolframMarkets as WM. Build a configuration with WM.build(WM.MyModelBConfiguration, data) and run it with WM.simulate (or WM.simulate_checked, which also asserts the conservation and price identities). :reserve is the supported clearing mechanism.

Non-verbatim edits to the snapshot files -

  1. Wrapped in this module; build is imported from the course package so the constructors extend it.
  2. Dropped Model A (open model) with its types, builders, simulate method and Files.jl, together with the unused MyBandEdgeAgentModel, MyEndogenousPriceModel and MyModelBSimulation types and builders.
  3. Dropped the Following, FollowingMetrics, PaperStyle and StripPanels files (figures and advice only).
  4. Removed the two ProgressMeter uses in the Model B simulate (no random draws involved).
  5. The default of the clearing keyword is :reserve (the snapshot's default is :legacy, which is kept in place but is internal and undocumented).
  6. Runtime.jl is simulate_repaired of the snapshot's rebuild/RebuildRuntime.jl as simulate_checked, without the ledger write.
  7. Course addition, not a paper result: Simulate.jl accepts boundary_mode = :random with the keywords random_edge_probabilities and random_edge_seed. Only the edge-classification branch changes; the draws come from a separate Xoshiro stream (default seed config.seed + 7919), so the main RNG draw order and the parity SHA-256 fingerprints of the paper modes are untouched. The boundary_mode error message now names all three modes.
  8. The verbose docstring line of simulate no longer claims a ProgressMeter bar (the keyword is a no-op since edit 4).

VLQuantitativeFinancePackage.WolframMarkets.MyModelBSimulationResult — Type
MyModelBSimulationResult

Immutable container for a Model B run: sparse grid snapshots plus the COMPLETE aggregate trajectory, so all statistics are computed from every step.

State-like series (length steps+1, index 1 = t=0): prices, emaprice, emavolatility, bandlower, bandupper (nominal-k band, for plotting), buyfraction, holdfraction, sellfraction, totalcash, totalshares. Transition-like series (length steps, index t = step t): logreturns (= λ·φ{t-1} only under legacy clearing), netimbalance (EXECUTED imbalance φ{t-1}, the value that generated Pt), edgebuycount/edgeholdcount/edgesellcount (counts of e{i,t} over active edge agents), executedbuys, executedsells, suppressedbuys, suppressedsells, marketmakerrejectedbuys, and marketmakerrejected_sells. Suppression means the submitting agent lacked cash/shares (or failed the cost-basis rule); rejection means the agent was eligible but the finite market maker lacked counterparty capacity.

marketmakercash and marketmakerinventory are state-like series. In the unlimited limit they are allowed to become negative and record the borrowing or short position required to support the historical fill-all convention.

edgeswitches = Σi Σt [e{i,t} ≠ e{i,t-1}], baseline e{i,0} = Hold. finalbooks holds the trading-cell balance sheets at t = steps. edgek[i] is the band half-width of the agent at edge_coordinates[i] (same order). frames always contains t=0 and t=steps.

VLQuantitativeFinancePackage.build — Method
build(MyModelBConfiguration, data::NamedTuple) → MyModelBConfiguration

Required keys: numberofrows, numberofcols. Optional keys (defaults): numberofcolors (3), radius (4), steps (200), seed (42), initialcondition (:balancedperturbation), initialbuyfraction (0.05), initialsellfraction (0.05), edgefraction (0.25), α (1/60), k (1.0), λ (0.01), P0 (100.0), minorityfraction (0.20), rulemajorindex (19280), ruleminorindex (19286), initialcash (1000.0), initialshares (10), costbasisrule (true), edgebandspread (0.5). marketmakercapacity (Inf), measured as symmetric net units per trading agent. Inf is the historical fill-all execution limit; a finite nonnegative value constructs an explicit capacity-constrained dealer.

Validates: steps > 0; grid at least 3×3 (interior must be non-empty); all fractions in [0, 1]; initialbuyfraction + initialsellfraction ≤ 1; known initial_condition; P0 > 0. Throws ArgumentError on violation.

VLQuantitativeFinancePackage.WolframMarkets.simulate — Function
simulate(config::MyModelBConfiguration; initial_grid, snapshot_steps,
         intervention, minority_population, rule_activation_step,
         boundary_mode, random_edge_probabilities, random_edge_seed, verbose)
    → MyModelBSimulationResult

Run the closed-loop (Model B) simulation with per-agent budget constraints and an explicit market maker. config.market_maker_capacity = Inf is the exact historical fill-all limit; finite values constrain the maker's symmetric net capacity per trader.

Step t (t = 1..steps) transforms X{t-1} → Xt in this exact order:

o_i     = desired orders (interior grid states; e_{i,t-1} for edges)
x_i     = execution filter + settlement at the standing quote P_{t-1}:
          buy iff cash ≥ P; sell iff shares ≥ 1 and
          (¬cost_basis_rule or P > avg_cost)
φ_{t-1} = (executed buys − executed sells) / N_traders
P_t     = P_{t-1} · exp(λ · φ_{t-1})          (log return = λ·φ_{t-1})
μ_t     = μ_{t-1} + α·(P_t − μ_{t-1})         (EMA sees the NEW price)
σ_t     = σ_{t-1} + α·(|P_t − μ_t| − σ_{t-1})
e_{i,t} = BandState(P_t, μ_t, σ_t, k_i)       → active edge cell i
X_t     = CA step on interior of X_{t-1}      (edge neighbors see e_{i,t})

Ntraders = Ninterior + Nactiveedge, fixed for the run. All randomness comes from Xoshiro(config.seed), consumed in fixed order: (1) edge-cell sampling, (2) edge band half-widths, (3) initial-grid perturbation, (4) minority rule assignment. Same config ⇒ identical output.

Arguments

  • config : MyModelBConfiguration (single source of truth)
  • initialgrid : required iff config.initialcondition == :custom
  • snapshot_steps: steps at which to store full grid frames (default: 8 log-spaced); t = 0 and t = steps are always stored
  • intervention : optional (t, books) -> nothing hook called at the TOP of step t, before orders execute at P_{t-1}. May mutate the books in place (e.g. a mid-run liquidity injection). Must be deterministic in (t, books) — no RNG — or the same-config ⇒ identical-output contract breaks.
  • minoritypopulation : `:allsites(historical behavior) or:interior`. The latter assigns exactly round(f*N_interior) minority rules among updateable interior cells.
  • ruleactivationstep : optional delayed rule quench. When set, the sites designated by minority_fraction initially follow the major rule and switch to their preselected minor rule at the top of this step. Set to steps + 1 for the paired matched no-switch control. nothing preserves the historical model, in which minority rules are active from t = 0.
  • boundary_mode : :endogenous (default) lets the updated price classify the active edge ring. :hold clamps the same sampled edge sites to Hold while retaining the identical RNG stream, trader denominator, books, and fixed-boundary CA geometry. This is the matched autonomous-CA ablation. :random (course addition, not a paper result) draws each edge trader's state independently every step from a separate Xoshiro stream, ignoring the price. Edges start in Hold and a draw at step t places its order at step t+1, exactly like an :endogenous edge.
  • randomedgeprobabilities : (Buy, Hold, Sell) probabilities of the :random mode, a Float64 3-tuple, nonnegative, summing to 1 within 1e-12 (default (1/3, 1/3, 1/3)). Course addition, not a paper result.
  • randomedgeseed : seed of the :random edge stream; nothing means config.seed + 7919. The main RNG draw order is untouched.
  • activationaction : :rule switches target rules; `:sellpulse` instead writes Sell once at the same targets before orders, retaining the baseline rule. Requires delayed activation.
  • fixedbandstep : freeze the boundary decision deviation at its value just before this step; the center and diagnostic deviation continue updating. The pre-intervention path is unchanged.
  • verbose : accepted for compatibility; has no effect (the progress bar was removed)
  • observer : optional decision/measurement observer. It runs before orders and after settlement/repricing; legacy state histories still describe the end-of-step local update.
  • clearing : :legacy reproduces the archived standing-quote model, which permits profitable round trips. :reserve uses a finite constant-product dealer, actual-price eligibility, and the final reserve ratio as price; lambda does not apply.

Returns MyModelBSimulationResult; see its docstring for the series-length conventions (state-like: steps+1; transition-like: steps).

VLQuantitativeFinancePackage.WolframMarkets.simulate_checked — Function
simulate_checked(config; kwargs...) → MyModelBSimulationResult

Run simulate with clearing = :reserve and then assert the run's invariants: cash and shares (traders plus dealer) are conserved, prices are finite and positive, no trader ends with negative cash or shares, the dealer's cash times inventory stays constant, and each price equals the dealer's cash-to-inventory ratio. The configuration must have finite market_maker_capacity. clearing cannot be passed.

VLQuantitativeFinancePackage.WolframMarkets.compute_max_drawdown — Function
compute_max_drawdown(prices) → Float64

Largest peak-to-trough fractional decline: max over t of 1 − Pt / max{s≤t} P_s. Zero for a monotone non-decreasing series.

VLQuantitativeFinancePackage.WolframMarkets.rule_table — Function
rule_table(R::Int64)::Vector{Int64}

The nine actions $a_0,\dots,a_8$ of the two-dimensional totalistic Wolfram rule number R: the base-3 digits of R, least significant first, so index k + 1 is the action for neighbor sum k (0 = Buy, 1 = Hold, 2 = Sell). Throws an ArgumentError unless 0 ≤ R < 3^9.

The configuration of the rule-switch experiment on an L × L grid (including the edge ring): minority fraction f, dealer depth h (the market_maker_capacity), steps = t_pre + t_post. Every field is set explicitly to the paper's value (baseline Rule 19280, switch Rule 19286).

VLQuantitativeFinancePackage.WolframMarkets.run_rule_switch — Function
run_rule_switch(; L, f, h, seed, boundary_mode, t_pre = 1000, t_post = 3000, f_control = f, kwargs...)

Run the switched arm (minority fraction f, the rule switches at step t_pre + 1) and the control arm (minority fraction f_control, no switch within the horizon) through simulate_checked, both with :interior minority placement, the rule activation action, and frames stored at t_pre and t_pre + t_post. Extra kwargs (for example random_edge_probabilities with boundary_mode = :random) go to both arms. Asserts that the two arms share their history up to the switch. Returns (switched, control, t_pre).

VLQuantitativeFinancePackage.WolframMarkets.rule_switch_summary — Function
rule_switch_summary(pair; window = 500)::NamedTuple

Summarize the output of run_rule_switch with the paper's per-run definitions. final_sell_mean is the mean sell fraction over the last min(t_post, window) steps; onset is the number of steps after the switch to the first sell fraction ≥ 0.5 (0 if none) and transitioned is onset > 0; max_drawdown is compute_max_drawdown of the post-switch prices. The control_* fields are the same quantities for the control arm.
