# L10b optional advanced material

This folder contains optional extensions rather than production lecture
material. Students should complete the core protective-collar/TJUL lecture in
the parent folder and L10a before beginning these notebooks.

## Advanced lecture

- `CHEME-5660-L10b-Lecture-American-WheelFunds-Fall-2026.ipynb` models the
  Wheel as a path-dependent policy that alternates between a cash-secured-put
  state and a covered-call state.

## Advanced examples

- `CHEME-5660-L10b-Example-Delta-VerticalCallSpread-Fall-2026.ipynb`
- `CHEME-5660-L10b-Example-AnalysisCoveredCall-Fall-2026.ipynb`
- `CHEME-5660-L10b-Example-AnalysisSyntheticCoveredCall-Fall-2026.ipynb`
- `CHEME-5660-L10b-Example-CashSecuredPut-Fall-2026.ipynb`

The covered-call and cash-secured-put notebooks revisit L10a at greater depth;
the Wheel notebook combines them into a sequential inventory policy. Historical
download bundles and the data required by these notebooks are kept in the
`md/` and `data/` subfolders.
