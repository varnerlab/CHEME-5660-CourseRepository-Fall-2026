Optional: Explore FRED economic data

Needed for: nothing graded
Cost: free
Time: about 10 minutes

FRED (Federal Reserve Economic Data) is a free database of economic time series from the Federal Reserve Bank of St. Louis. The Advanced track of PS6 uses four FRED series, which come in a data file with PS6, so PS6 needs no FRED key. If you want to explore other series, you can get your own key and use it from Julia or from Claude Code.

FRED identifies each program by an API key, a string of 32 lowercase letters and numbers. Every request to FRED carries the key.

Step 1: Create a FRED account

  1. Go to fredaccount.stlouisfed.org/apikeys.
  2. Create a free account, or sign in if you already have one. You can use your Cornell email address.
  3. Confirm your email address if FRED sends you a confirmation link.

Step 2: Request an API key

  1. On the API Keys page, select Request API Key.
  2. FRED asks how you will use the key. A short answer is enough, for example: Class work for CHEME 4660/5660 at Cornell University.
  3. Agree to the terms of use and submit the request.
  4. Your new key appears on the API Keys page. You can return to this page at any time to view it again.

Step 3: Use your key

  • From Julia: the FredAPI package calls the 36 endpoints of the FRED API and turns each response into a DataFrame. Its README shows how to install the package, store your key in conf/Configuration.toml, and download the observations of a series.
  • From Claude Code: CHEME 5800 built an MCP server that offers one tool for each FRED endpoint, so you can ask about FRED data in plain English. Download the CHEME 5800 course repository, and follow the README of its L13d folder.

Keep your key private

Treat your API key like a password. Do not paste your key into a notebook, a Canvas submission, or a discussion post, and do not commit Configuration.toml to GitHub. If you think your key was exposed, delete it on the FRED API Keys page and request a new one.
