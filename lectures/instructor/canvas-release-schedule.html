How the weekly course materials are released

Lecture notebooks and examples are published on the course repository's GitHub Releases page as ZIP bundles that you download and open in VS Code. Starting with week 6, each week's materials are released one class meeting at a time rather than all at once. This page explains when releases appear, how they are numbered, and which one to download.

One release per class meeting

Each week has two class meetings, labeled a and b (for example L6a and L6b in week 6). The materials for a meeting are released before that class, typically the evening before. The revision number at the end of the release name tells you which meetings the bundle contains.

Release Contains Available before
week-06.0L6aTuesday's class
week-06.1the complete week (L6a, L6b)Thursday's class

The same pattern holds every week: .0 is Tuesday's meeting only, and .1 is the complete week. Weeks 1 through 5 were released before this change, so their releases contain the complete week.

Releases are cumulative

Every release contains all earlier meetings of the same week. You do not need to keep several bundles for one week. Always download the most recent release for the current week and work from it. The release title shows what is inside, for example Week 06 (L6a); a title with no list, such as Week 06, is the complete week.

Corrections

If we find a problem in a notebook that has already been released, the fix ships with the next release of that week. Published releases are never edited in place. After Thursday's meeting, any further release (week-06.2, week-06.3, and so on) contains the complete week with corrections, and its release notes say what changed.

How to download a release

  1. Open the course Releases page.
  2. Select the most recent release for the current week.
  3. Under Assets, download the file named CHEME-5660-Fall-2026-Week-NN.R.zip. Do not download the automatically generated Source code archives.
  4. Extract the ZIP completely, open the extracted folder in VS Code, and follow the setup and notebook instructions in its README.md. The week's README lists every meeting; links to meetings not yet released work once you download a later release.

If a bundle behaves unexpectedly, check that you have the most recent release for the week before anything else. Bring the release name and the exact error message to office hours if the problem continues.
