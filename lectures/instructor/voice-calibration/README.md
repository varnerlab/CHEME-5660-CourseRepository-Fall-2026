# Voice-calibration backups (CHEME 5660)

One folder per round, named for the notebook: `<notebook-slug>/before.ipynb` plus
a `README.md` naming the source notebook path, the commit it was copied from, and
the date. The protocol, and the lessons learned from each round, are in
[the shared notebook style guide](../NOTEBOOK-STYLE-GUIDE.md) under
"Voice-calibration experiment".

To start a round: tell the assistant which notebook you are about to hand-edit.
To finish one: say the round is done, and ask it to compare.
