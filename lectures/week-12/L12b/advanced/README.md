# L12b optional advanced material

This folder holds one notebook. It is a derivation with no code.

- [`qlearning/CHEME-5660-L12b-Advanced-QLearning-Fall-2026.ipynb`](qlearning/CHEME-5660-L12b-Advanced-QLearning-Fall-2026.ipynb)
  asks how a trader could learn a policy table from experience instead of being
  handed one. A Wolfram rule is a policy table, and the lecture's traders are
  given theirs. The notebook writes the Q-learning update for the value of each
  action in each state, lays out the algorithm step by step, and describes the
  conditions on the learning rate and on exploration under which it converges to
  the best policy. The lecture links it and lists it in its Optional Advanced
  Material section.
