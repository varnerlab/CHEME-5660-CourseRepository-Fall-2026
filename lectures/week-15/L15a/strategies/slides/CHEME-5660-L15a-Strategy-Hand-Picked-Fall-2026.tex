\begin{frame}{The Idea}
  \vspace{0.3em}
  The hand-picked rule holds the same list of tickers at every decision. The menu has two lists, chosen without
  looking at the 2025 prices:
  \begin{itemize}\setlength{\itemsep}{0.5em}
    \item \hilite{\texttt{l8b\_13}}: \texttt{AAPL}, \texttt{MSFT}, \texttt{INTC}, \texttt{MU}, \texttt{AMD}, \texttt{NVDA}, \texttt{GS}, \texttt{BAC}, \texttt{WFC}, \texttt{C}, \texttt{F}, \texttt{GM}, \texttt{JNJ}.
    \item \hilite{\texttt{l8b\_15}}: the same 13 tickers, plus \texttt{WMT} and \texttt{PG}.
  \end{itemize}

  \vspace{0.5em}
  Each list is its own picking entry on the menu, \textbf{hand-picked l8b\_13} and \textbf{hand-picked l8b\_15}.
  With a fixed list, the results show what the weighting rule adds when the basket never changes.
\end{frame}

\begin{frame}{The Rule}
  \vspace{0.3em}
  On every decision day $t$, the basket $\mathcal{B}(t)$ is the chosen list:
  \begin{enumerate}\setlength{\itemsep}{0.5em}
    \item Find each ticker of the list in the universe. The rule stops with an error when a ticker is missing.
    \item Return the tickers in the order of the universe.
  \end{enumerate}

  \vspace{0.5em}
  The rule ignores the preference weights and the market data. The basket is the same at every decision.
\end{frame}

\begin{frame}{Reading the Code}
  \vspace{0.3em}
  The rule's code file is
  \href{\repo/strategies/picking/hand_picked.jl}{\texttt{strategies/picking/hand\_picked.jl}}:
  \begin{itemize}\setlength{\itemsep}{0.5em}
    \item \texttt{pick\_hand\_picked(tickers, basket)} finds the list's tickers in the universe.
    \item \texttt{MyL15aHandPickedScreen} is the type the engine calls. It holds the list \texttt{basket}.
    \item The lists live under \texttt{[grid.fixed\_lists]} in the study settings file \texttt{code/src/data/mpc/study.toml}, and \texttt{menu.jl} adds one menu entry for each list.
    \item \texttt{MPC.pick(screen, md, t; ...)} runs at each decision and returns the basket's columns in the market data.
  \end{itemize}

  \vspace{0.5em}
  The \href{\repo/strategies/CHEME-5660-L15a-Strategy-Menu-Fall-2026.ipynb}{strategy menu} lists every rule, and the \href{\repo/engine/CHEME-5660-L15a-Trading-Engine-Fall-2026.ipynb}{trading engine} describes the triggers that start each decision.
\end{frame}
