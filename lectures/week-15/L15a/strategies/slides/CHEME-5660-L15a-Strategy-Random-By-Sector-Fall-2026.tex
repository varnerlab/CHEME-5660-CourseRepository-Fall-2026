\begin{frame}{The Idea}
  \vspace{0.3em}
  The random-by-sector rule draws three tickers at random in each sector, the same basket shape as the
  gamma-by-sector rule:
  \begin{itemize}\setlength{\itemsep}{0.5em}
    \item \hilite{Basket}: three tickers in each of the 11 sectors and three of the 14 exchange-traded funds (ETFs), 36 tickers in all.
    \item \hilite{Reason}: a random basket shows how a basket of the same shape does by luck alone.
    \item \hilite{Seeds}: the saved results run each random rule with 30 seeds in the backtests and 5 in the stress tests.
  \end{itemize}

  \vspace{0.5em}
  The engine draws a new basket at each decision: on the start day and whenever a trigger fires.
\end{frame}

\begin{frame}{The Rule}
  \vspace{0.3em}
  On decision day $t$, split the universe into its 12 sectors $\mathcal{S}_{1},\dots,\mathcal{S}_{12}$, with
  the ETFs as one sector:
  \begin{enumerate}\setlength{\itemsep}{0.5em}
    \item In each sector $\mathcal{S}_{j}$, draw three distinct tickers at random, each set of three equally
      likely. A sector with three tickers or fewer gives all of them.
    \item The basket $\mathcal{B}(t)$ holds the tickers drawn in every sector.
  \end{enumerate}

  \vspace{0.5em}
  The random stream depends on the run's seed and the decision date, so the same seed and date give the same basket. Unlike the gamma rules, the rule ignores the preference weights.
\end{frame}

\begin{frame}{Reading the Code}
  \vspace{0.3em}
  The rule's code file is
  \href{\repo/strategies/picking/random_by_sector.jl}{\texttt{strategies/picking/random\_by\_sector.jl}}:
  \begin{itemize}\setlength{\itemsep}{0.5em}
    \item \texttt{pick\_random\_by\_sector(tickers, sectors, rng; count)} draws \texttt{count} tickers in each sector from the random stream \texttt{rng}.
    \item \texttt{MyL15aRandomSectorScreen} is the type the engine calls. The rule has no settings of its own.
    \item \texttt{MPC.pick(screen, md, t; N, seed, ...)} builds one random stream for the decision date with the run's \texttt{seed}, draws \texttt{N~=~3} tickers per sector, and returns the basket's columns in the market data.
  \end{itemize}

  The \href{\repo/strategies/CHEME-5660-L15a-Strategy-Menu-Fall-2026.ipynb}{strategy menu} lists every rule, and the \href{\repo/engine/CHEME-5660-L15a-Trading-Engine-Fall-2026.ipynb}{trading engine} describes the triggers that start each decision.
\end{frame}
