# L2a optional advanced material

These standalone notebooks extend the L2a discussion of Treasury securities
and default risk. They are optional and are not prerequisites for L2b.

- [`default-risk/CHEME-5660-L2a-Advanced-Bernoulli-DefaultRisk-Fall-2026.ipynb`](default-risk/CHEME-5660-L2a-Advanced-Bernoulli-DefaultRisk-Fall-2026.ipynb)
  represents uncertain principal and coupon payments with Bernoulli survival
  indicators, adds recovery following default, and verifies the analytical
  expected-value price by Monte Carlo simulation.
