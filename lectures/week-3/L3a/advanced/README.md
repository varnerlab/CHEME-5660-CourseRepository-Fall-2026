# L3a optional advanced material

These standalone modules extend the L3a discussion of exchanges and returns
into market microstructure. They are optional and are not prerequisites for
L3b.

- [`order_book/CHEME-5660-L3a-Advanced-LimitOrderBook-Mechanics-Fall-2026.ipynb`](order_book/CHEME-5660-L3a-Advanced-LimitOrderBook-Mechanics-Fall-2026.ipynb)
  develops the state and event mechanics of a price-time-priority limit-order
  book.
- [`market_impact/CHEME-5660-L3a-Advanced-Market-Impact-Models-Fall-2026.ipynb`](market_impact/CHEME-5660-L3a-Advanced-Market-Impact-Models-Fall-2026.ipynb)
  distinguishes mechanical execution cost from linear, order-flow-imbalance,
  and transient-impact models.

Work through the order-book notebook first. The market-impact notebook assumes
its vocabulary and uses the same `VLQuantitativeFinancePackage` implementation.
