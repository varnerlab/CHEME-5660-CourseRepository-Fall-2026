# L3b optional advanced material

These standalone notebooks extend the L3b discussion of binomial equity-price
lattices. They are optional and are not prerequisites for L4a.

- [`recombination/CHEME-5660-L3b-Advanced-Recombination-ComputationalCost-Fall-2026.ipynb`](recombination/CHEME-5660-L3b-Advanced-Recombination-ComputationalCost-Fall-2026.ipynb)
  compares the full path tree with its recombined lattice and shows exactly
  when time-dependent moves stop recombining.
- [`calibration/CHEME-5660-L3b-Advanced-Bootstrap-LatticeCalibration-Fall-2026.ipynb`](calibration/CHEME-5660-L3b-Advanced-Bootstrap-LatticeCalibration-Fall-2026.ipynb)
  bootstraps historical returns to measure uncertainty in the estimated
  lattice parameters and in forecasts computed from them.

The recombination notebook explains the model structure. The calibration
notebook is the larger applied exercise and can be completed independently.
