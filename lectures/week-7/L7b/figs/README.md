# L7b figures

The three PNG files are the inline plot outputs of the L7b example notebooks,
extracted from the executed notebooks (the notebooks do not write files); the
deck includes them. To refresh them, re-execute the example and export the
plot output again.

- `Fig-L7b-Rolling-Beta-Bands.png`: Example 1, rolling one-year betas with 95%
  bands against the archive and close-based full-sample values (NVDA, AAPL,
  JNJ, GS).
- `Fig-L7b-Online-Paths-2025.png`: Example 1, online intercept and beta paths
  through 2025 against the frozen archive values.
- `Fig-L7b-Paired-Differences.png`: Example 2, paired online minus frozen
  terminal wealth over the scenario ensemble.
